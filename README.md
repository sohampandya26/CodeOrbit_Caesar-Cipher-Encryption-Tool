# Caesar Cipher Encryption Tool

A Python command-line tool that encrypts and decrypts text using the classic Caesar Cipher technique, with a user-chosen shift value (key).

Built for the **CodeOrbit Tech Cyber Security Internship** — Task 2 of 6.

## What It Does

- Encrypts plaintext by shifting each letter forward by a chosen key
- Decrypts ciphertext back to the original text using the same key
- Leaves spaces, numbers, and punctuation unchanged
- Displays both the encrypted and decrypted output clearly

## Technologies Used

- Python 3 (standard library only — no external packages required)

## Setup Instructions

1. Clone this repository:
   ```
   git clone <your-repo-url>
   cd <your-repo-folder>
   ```
2. Make sure Python 3 is installed:
   ```
   python --version
   ```
3. Run the script:
   ```
   python caesar_cipher_tool.py
   ```
4. Choose to encrypt or decrypt, enter your text, and enter a shift value (key).

## Example

```
=== Caesar Cipher Encryption Tool ===
1. Encrypt a message
2. Decrypt a message
Choose an option (1 or 2): 1
Enter your text: Hello World
Enter shift value (key), e.g. 3: 3

Original text:   Hello World
Encrypted text:  Khoor Zruog
Decrypted back:  Hello World
```
